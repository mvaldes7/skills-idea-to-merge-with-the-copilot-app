# Mona's Bookmark Manager Roadmap

Plan for making bookmarks easier to find, organize, and keep safe.

| Area | Item | Type | Priority |
| --- | --- | --- | --- |
| Discovery | Search and filter bookmarks | 🚀 | High |
| Editing | Edit a saved bookmark | 🚀 | Medium |
| Organization | Add tags or folders | 🚀 | Medium |
| Portability | Import and export bookmarks | 🚀 | Medium |
| Customization | Customize the bookmark plug-in | 🚀 | Medium |
| Data integrity | Prevent duplicate slugs on re-add | 🐞 | Medium |
| Validation | Reject empty bookmark URLs | 🐞 | High |
| Persistence | Protect bookmarks from localStorage clearing | 🐞 | Medium |

## 🚀 Planned features
- 🔖 Search & filter bookmarks — priority: high
- ✏️ Edit a saved bookmark — priority: medium
- 🏷️ Organize bookmarks with tags or folders — priority: medium
- 📦 Import & export bookmarks — priority: medium
- 🧩 Customize the bookmark plug-in — priority: medium

## 🐞 Known bugs & risks
- 🐞 Duplicate slugs on re-add — priority: medium
- 🐞 Empty-URL validation may allow invalid bookmarks — priority: high
- 🐞 Clearing localStorage can permanently lose bookmarks — priority: medium
